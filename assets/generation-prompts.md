# ImageGen Prompt Set

Generated with the built-in ImageGen workflow. The source dashboard was used only as a visual master for palette, card language, map illustration style, icons, and mascot consistency.

## Shared UI-screen prompt

Create a high-fidelity, globally usable desktop web-app screen for an AI Smart Travel & Emergency Assistant. Preserve the reference dashboard's mint sidebar, white rounded cards, deep-navy typography, teal actions, orange caution accents, friendly illustrated maps, and teal elephant safety mascot. Keep the layout practical and readable. Avoid country-specific emergency numbers, flags, identifiable landmarks, real-company logos, mobile frames, watermarks, tiny paragraphs, and gibberish.

### `00-login.png`

Design a clean 16:9 split-screen login page. Use a global travel illustration and the official teal elephant mascot on the left; place the official logo and a spacious authentication card on the right. Include `Welcome back`, Email address, Password, Remember me, Forgot password, Sign in, Continue with SSO, Create an account, Continue as guest, and an unauthenticated `Open Emergency Center` link. Keep all imagery globally neutral and reuse the established mint, teal, navy, orange, and coral design system.

### Login component asset pack

- Hero background: isolate the globally neutral coastal landscape as a square CSS-cover background, leaving open mint sky for HTML copy. Exclude all text, mascot, logo, airplane, route, and pins.
- Route overlay: isolate the teal-and-white airplane, curved white dotted route, route nodes, and teal pins on a genuine transparent background.
- Form icons: create an exact 4 × 2 transparent sprite sheet containing email, lock, eye, globe, SSO users, checked square, right arrow, and SOS shield icons with consistent geometry.
- Corner decoration: create a low-contrast transparent cluster of mint leaves and rounded hill shapes for the form panel's lower-right corner.

## Reusable asset prompts

### Logo

Create an original mint-to-teal brand mark combining a location pin, protective shield, and compass. Produce a horizontal lockup with the exact wordmark `Smart Travel Assistant` and a separate square app mark. Use a genuine transparent background, clean flat-vector styling, and no mockup scene.

### Mascot

Create the same teal elephant travel-safety guide from the visual master: rounded proportions, large ears, rosy cheeks, orange rescue backpack, orange vest, and a white location-pin badge. Produce three transparent full-body PNG states: welcoming wave, helpful warning, and emergency helper with first-aid kit.

### Icons

Create 12 cohesive web UI icons in a 4 × 3 transparent grid: rain, train, airplane, route, map pin, shield, warning, SOS siren, medical cross, AI bot, globe, and notification. Use consistent rounded geometry and the product palette.

### Hero banner

Create a wide global travel-and-safety panorama with abstract mountains, coast, city, forest, train, airplane, and a dotted travel route. Keep generous pale copy space on the left. Do not include text, flags, or identifiable landmarks.

### Background pattern

Create a seamless low-contrast warm-white and mint pattern using contour lines, dotted routes, location pins, clouds, compass stars, and shields. No focal point or text.

### Global map base

Create a simplified world map with pale blue oceans, light mint/cream continents, and subtle terrain textures. Do not include labels, borders, pins, routes, hazards, or text.
